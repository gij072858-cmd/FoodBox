# 成员二任务书 — 食材调料库模块

> 依据：《01-食匣详细构想.md》第二章 2.2 节（库）、《02-开发总计划.md》。逐周安排与总计划第四章一致。
> 你的模块是"库"——食匣的数据基石。菜式推荐与时序扣减都建立在你的库存数据之上。

---

## 一、职责定位

- **模块责任（主）**：库模块全部 UI 与逻辑——食材/调料双分区、卡片双模式排列、卡片详情页、手动录入与扫码录入、有效期管理、临期提醒；
- **角色责任（辅）**：食材/调料基础数据整理（200+ 条）、库模块测试用例编写。

---

## 二、详细任务清单

### A. 数据建设（W1–W2，先行任务）

- [ ] 整理食材/调料基础库 JSON（≥200 条），每条含：名称、分类、类型（食材/调料）、默认保质期天数、默认存放位置（冷藏/冷冻/常温）、简介四段模板（是什么/怎么用/怎么存/小贴士）
- [ ] 覆盖度要求：常见蔬菜、肉禽蛋、水产、豆制品、米面主食、常用调料（油盐酱醋香料）全覆盖
- [ ] 配图（按修订后的图片策略）：优先为高频食材/调料收集**真实高清图**（小范围使用）；收集不到的列入缺图清单，由 AI 生成统一风格图兜底
- [ ] 配合组长跑通 JSON 导入与字段校验

### B. 库页面（W3，主攻周）

- [ ] 页面双分区结构：上「现有食材」+ 下「现有调料」，各自独立滚动
- [ ] 分区标题行：H2 标题 + 「共 N 项」计数 + 排列切换按钮（带动效 300ms）
- [ ] **大卡片水平轮转模式**：3:4 竖卡、一屏露 2.5 张、手动滑动 + 闲置 3 秒自动滚动（触碰暂停 10 秒）——直接使用成员四的公共组件，不自造轮子
- [ ] **竖直列表模式**：每行 64px，左 48×48 圆角缩略图 + 中间双行文本 + 右侧状态图标，限定约 5 行内滚动
- [ ] 卡片视觉严格按构想 2.2.2：满铺图 + 底部 40% 渐变蒙版 + 白色文字（名称 18px Bold + 属性行「剩余天数 + 数量」13px 半透明，Q1-B/Q2-B）
- [ ] 临期（≤3 天）橙色角标、过期红色角标

### C. 卡片详情页（W3–W4）

- [ ] 顶部大图（屏高 35%，下滑返回手势）
- [ ] 有效期区：未设置显示「+」按钮 → 点击后按预置保质期自动算出到期日（入库日期 + 默认保质期，按存放位置校正），弹出层中可修改后确认（Q3-C）；已设置显示大字「剩余天数」+ 到期日小字 + 进度（Q2-B）；可重新编辑
- [ ] 入库日期与存放位置展示
- [ ] 统一格式简介卡（是什么/怎么用/怎么存/小贴士 四段固定模板，可编辑）
- [ ] 操作区：编辑信息、数量调整（消耗/补充）、关联条码、删除

### D. 录入流程（W3 手动 + W4 扫码）

- [ ] 手动录入：搜索预置库 → 选中 → 填数量/日期 → 完成；数量**双模式自选**（粗粒度"有/不多/快没了" 或 精确数量 + 单位，条目创建后可切换，Q5-C）；支持「自建条目」（按模板填空）
- [ ] 扫码录入：mobile_scanner 接入 → 本地条码映射表匹配 → 命中自动填名称/品牌/保质期；未命中引导手动选择并**记忆该条码关联**（自学习）
- [ ] 电脑端降级：手动输入条码号

### E. 联动与收尾（W5–W6）

- [ ] 库存消耗联动：对接组长的 `PantryRepository.consume()`，时序执行后自动扣减；归零条目灰显并提示「已用完」
- [ ] F3 临期提醒本地通知（期1 必做）：剩 3 天 / 1 天时推送，点击直达该食材详情
- [ ] 库模块 bug 清零，通过成员四 UI 走查

## 五、交付物清单

**代码**：`features/pantry/` 目录全部（页面、组件、逻辑）。
**数据**：食材/调料基础库 JSON（≥200 条）。
**文档**：详细设计文档「库模块」章节、库模块测试用例表（交成员四汇总）。

## 六、验收标准

- 双模式切换流畅，自动滚动规则（闲置启动/触碰暂停）符合构想 2.2.1；
- 录入 → 详情 → 编辑 → 删除全流程无阻断 bug；空库状态有优雅空态页；
- 扫码命中/未命中两条路径都可用；条码关联记忆生效（同一商品二次扫码直接命中）；
- 临期/过期角标准确；库存被时序扣减后数量正确、归零灰显；
- 通过 UI 走查（圆角/蒙版/字号符合设计规范）。

## 七、与其他模块的接口约定

| 你依赖 | 你提供 |
|---|---|
| 组长：`PantryRepository` 接口与本地实现、Theme 常量 | 准确的库存数据（数量字段语义按 Q5 结论执行） |
| 成员四：水平自动滚动组件、蒙版卡片（FoodCard）、Section Header | 库模块测试用例表（W6 交成员四） |
| 组长：`consume()` 回调联调 | 库关闭模式的降级表现正常（构想 2.2.7） |

**纪律**：不直接操作数据库，一切走 `PantryRepository`；改共享区文件（`core/`/`data/`/`widgets/`）需在 PR 标题加 `[shared]` 并群里同步。
