## 六、验收标准

- 组件库覆盖构想第一章全部设计规范；组员页面全部使用公共组件（无私自重写的卡片/倒计时、无硬编码色值）；
- **动效系统 v2.1 落地**：全组动效统一走 `FBMotion` 常量与 `fb_animations.dart` 组件，无魔法数字；按压反馈缩放、入场错位节奏一致；
- 水平倒计时条组件多实例并行、后台恢复、完成提示全部正确（这是全组共用组件，出问题影响面最大）；
- 动态占位页演示效果达到"看不出是占位"的精致度（答辩演示用）；
- 我的页面三栏挪移动效流畅，数据与收藏状态全局同步；XP 进度条与厨阶随 XP 变动正确升级（规则按构想 2.6）；
- 术语表词条无常识性错误，术语弹层在详情页点开/关闭流畅；
- F6 导出/导入入口可用，存储位置可修改；
- W7 走查 issue 清零；测试文档用例通过率与缺陷统计真实完整。
