动效系统（v2.1）

时长：instant 120ms（按钮/开关）· quick 200ms · normal 350ms（Modal/展开）· entrance 600ms（入场）· pageTransition 400ms · heroEntrance 800ms。
曲线：easeOutQuart (0.25,1,0.5,1)（默认入场）· easeOutExpo (0.16,1,0.3,1) · springLight (0.34,1.2,0.64,1)（轻回弹，列表弹出）。
按压反馈：卡片 0.98 · 按钮 0.96 · 图标 0.90；按压时阴影减弱，松手回弹。
动画组件（app/lib/widgets/fb_animations.dart）
组件用途
FbFadeInUp淡入 + 上滑入场（delay/duration/curve）
FbStaggerList列表项错位入场（step 50ms，上限 8 项）
FbPressFeedback按压缩小 + 阴影减弱回弹（所有卡片/按钮/列表行）
FbFloat上下轻浮动（空态插画 / Hero 装饰）
FbPulse脉冲缩放 1→1.08（新消息 / 提醒 / 角标）
FbCountUp数字从 0 滚动到目标值（前置/后缀可见）
FbAnimatedProgress进度条从 0 填充到目标值（默认 brand→暖橙渐变）
FbGradientBackground渐变背景 + 顶部辉光（Hero 区 / 空态氛围）

纪律：所有动效时长/曲线走 FBMotion 常量，禁止魔法数字；倒计时按"结束时间戳"渲染，不依赖周期计数。
