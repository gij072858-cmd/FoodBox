# 组件使用说明（一页纸）

> **版本**：设计系统 v2.0（Apple 毛玻璃）+ 动效系统 v2.1 · **负责人**：成员四
> **依据**：《01-食匣详细构想》1.3 设计规范 · **适用**：全组所有页面开发（`app/lib/features/**`）
> **想看效果**：跑起 App →「我的」页底部 →「组件库 Showcase」，或直接走路由 `/showcase`

## 一、30 秒上手

```dart
import '../core/theme.dart';          // ① 常量：颜色 / 字号 / 圆角 / 间距 / 阴影 / 动效
import '../widgets/fb_card.dart';     // ② 组件：一个文件一个组件，按需 import
import '../widgets/fb_pill_button.dart';
```

**只有两条路**：要常量去 `core/theme.dart`，要组件去 `widgets/fb_*.dart`。

**唯一硬纪律**：页面里**不得出现** `Color(0xFF…)`、`fontSize: 17`、`BorderRadius.circular(16)`、
`Duration(milliseconds: 350)` 这类字面量 —— 一律换成 `FBColor.*` / `FBText.*` / `FBRadius.*` /
`FBSpace.*` / `FBMotion.*`。

> 为什么较真：期2 深色模式（F5）要做到"零重构上线"，前提就是**颜色只在一处定义**。
> 走查时会逐页 grep `Color(0x`，命中即开 issue。

## 二、组件速查

### 布局与容器

| 组件 | 用途 | 关键参数 |
|---|---|---|
| `FbSectionHeader` | 模块标题行（自带左右页边距） | `title` `trailing` `padding` |
| `FbCard` | 标准白卡（圆角 16 + 柔和阴影） | `child` `height` `padding` `onTap` `image` `imageOverlay` `fadeInDelay` `heroTag` |
| `FbHeroCard` | 展示级大卡（推荐菜式，220 高） | `title` `subtitle` `tag` `image` `badge` `height` `onTap` |
| `FbCardImageOverlay` | 卡片底部渐变蒙版（配 `FbCard.image`） | `child` `beginColor` `endColor` |
| `FbGlassContainer` | 毛玻璃容器（导航/浮层/Sheet） | `child` `blur` `color` `borderRadius` `border` |
| `FbBottomSheet` | 底部弹层（顶部 28 圆角 + 抓手） | `child` `padding` `showHandle` |
| `FbGradientBackground` | 渐变背景 + 角落光晕（Hero/空态） | `child` `gradient` `glowColor` `glowRadius` |

### 内容与交互

| 组件 | 用途 | 关键参数 |
|---|---|---|
| `FbListTile` | iOS 列表行（左图 40×40 + 双行） | `leading` `title` `subtitle` `trailing` `onTap` `showChevron` `fadeInDelay` |
| `FbPillButton.primary / .secondary / .ghost` | 胶囊按钮三态 | `label` `icon` `onTap` `height` `expanded` |
| `FbAvatar` | 圆形头像（默认 80，我的页 88） | `image` `size` `borderWidth` `badge` |
| `FbBadge.dot()` / `FbBadge.count(n)` | 角标：小圆点 / 数字胶囊（>99 显示 99+） | `count` |
| `FbEmptyState` | 空态（浮动大图标 + 标题 + 说明 + 主次按钮） | `title` `message` `icon` `actionLabel` `onAction` `subActionLabel` `onSubAction` |
| `FbToast.show(context, '文案')` | 轻提示（深色毛玻璃胶囊，2 秒消失） | 静态方法，无需实例化 |

### 动效（`widgets/fb_animations.dart`，v2.1）

| 组件 | 效果 | 关键参数 |
|---|---|---|
| `FbFadeInUp` | 淡入 + 上滑入场 | `child` `delay` `duration` `curve` `offset` |
| `FbStaggerList` | 列表错位入场（每项 +50ms，最多 8 项） | `children` `step` `duration` `offset` |
| `FbPressFeedback` | 按压缩放反馈（卡片/按钮/列表行通用） | `child` `onTap` `onLongPress` `pressedScale` `pressedY` |
| `FbFloat` | 上下浮动循环（空态插画、装饰） | `child` `amplitude` `duration` |
| `FbPulse` | 脉冲缩放循环（新消息、提醒角标） | `child` `duration` `minScale` `maxScale` |

> **临时件**：`FbPlaceholder` 是 W1 空壳期的占位页组件，目前搜索页 / 动态页 / 菜式页 / 时序页
> 还在用，随各模块页面落地逐步消失，**新页面不要再引入它**。

## 四、四个可复制的组合

**① 标准的内容卡片区**

```dart
FbSectionHeader(title: '最近查看', trailing: Text('全部', style: FBTextStyle.caption)),
Padding(
  padding: FBSpace.pageH,
  child: FbCard(
    onTap: () => context.push('/home/pantry/1'),
    child: Text('番茄', style: FBTextStyle.body),
  ),
),
```

**② 带图片的菜式卡（3:4 蒙版卡）**

```dart
FbCard(
  height: 160,
  padding: EdgeInsets.zero,
  image: Image.network(url, fit: BoxFit.cover),
  imageOverlay: FbCardImageOverlay(
    child: Text('番茄炒蛋', style: FBTextStyle.h2Inverse),
  ),
  child: const SizedBox.shrink(),
)
```

**③ 列表错位入场（页面首屏列表统一这么写）**

```dart
FbStaggerList(
  children: <Widget>[
    for (final item in items)
      FbListTile(
        leading: ...,
        title: item.name,
        subtitle: item.note,
        onTap: () {},
      ),
  ],
)
```

**④ 空态**

```dart
FbEmptyState(
  title: '库还是空的',
  message: '去添加第一件食材，就能看到能做什么菜了。',
  icon: Icons.kitchen_outlined,
  actionLabel: '添加食材',
  onAction: () => context.push('/home/pantry/new'),
)
```

## 五、七个已知坑

1. **`FBTextStyle` 全是 getter，不是 `const`** —— 任何包着它的 widget 都不能加 `const`，
   否则报 `Invalid constant value`。写成 `Text('x', style: FBTextStyle.body)` 时就别再往外套 `const`。
2. **`FbCard` 用了 `image` 就必须配 `imageOverlay`** —— 否则白色 `child` 文字压在浅色图上会看不清；
   同时 `child` 传 `SizedBox.shrink()` 占位，`padding: EdgeInsets.zero`。
3. **`FbSectionHeader` / `FBSpace.pageH` 自带左右页边距** —— 外层不要再套一次
   `EdgeInsets.symmetric(horizontal: FBSpace.page)`，否则页面边距变 40。
4. **`FbPillButton` 的 `onTap` 传 `null` 会自动变成禁用态（50% 透明）** ——
   这是特性不是 bug；想保留可点但视觉弱化，用 `.ghost`。
5. **`FbListTile` 传了 `trailing` 就不显示右箭头** —— 要"箭头 + 右侧信息"两个都有，
   自己把箭头塞进 `trailing`。
6. **循环动效会让 `pumpAndSettle()` 永不返回** —— `FbFloat` / `FbPulse` 内部是
   `repeat(reverse: true)`，widget test 里只要页面用到它们（如「我的」页身份区），
   就得用 `await tester.pump(); await tester.pump(const Duration(milliseconds: 600));`
   代替 `pumpAndSettle()`，否则报 `pumpAndSettle timed out`。
7. **别用 `AnimatedSwitcher` 包裹 `navigationShell`** —— `StatefulNavigationShell`
   持有 GlobalKey，而 AnimatedSwitcher 在过渡期会同时保留新旧 child，同一个 GlobalKey
   出现在两处 → 抛 `Duplicate GlobalKey detected in widget tree`，widget 子树被截断
   （真机表现为切 Tab 时内容闪断）。Tab 切换动效统一走 `AppShell` 的「重放式淡入」。

## 六、要加一个新组件怎么办

组件库是共享区，**不是谁想加就往里塞**：

1. 判断**是否两个以上模块会用** —— 只有一个页面用的组件，先放在自己 `features/` 目录里；
2. 确实要进公共库 → 在**群里同步**（一句话说明：组件名 / 用途 / 关键参数）→ 在本文件第二节补一行；
3. 实现时：**只 import `core/theme.dart`**，外观参数一律给默认值取常量，禁止出现裸色值；
4. **同步在 `showcase_page.dart` 补一个演示区** —— 走查看不到 = 等于没有；
5. 提交说明加 `[shared]`。

> 组件 API 一旦发布，修改必须**向后兼容**或**全组同步**（加参数给默认值 = 兼容；改必填参数 = 破坏性）。
