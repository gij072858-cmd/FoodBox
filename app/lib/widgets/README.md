# lib/widgets/ —— 公共组件库（共享区）

> 负责人：**成员四**（设计规范守护者）。其他成员可提需求，但组件实现统一在这里收口。

## 为什么有这一层

同一个视觉元素被两个人各写一遍，是本项目最容易踩的坑（构想第四章改进 6 专门点名了
「自动滚动卡片区」）。所以凡是**两个及以上模块会用到的组件**，一律先在这里打样，再被引用。

## 纪律

1. 组件内部**必须**引用 `lib/core/theme.dart` 的常量，禁止硬编码色值 / 圆角 / 字号；
2. 改动本目录属共享区改动：PR 标题加 `[shared]`，并在群里同步；
3. 组件要能被"看见"——W2 需提供一个 showcase 演示页集中展示全部组件（总计划 W2 验收项）。
