# assets/images/ —— 图片资源

## 目录约定

```
images/
├── items/      食材 / 调料图（成员二）
├── recipes/    菜式成品图与步骤图（成员三）
│   └── steps/
└── icons/      分类封面等
```

## 策略（构想第四章改进 2）

真实高清图优先导入 → 缺图用 AI 生成统一风格兜底 → 用户条目允许自拍上传。

关键约束：**资源目录可整体替换，版式与图解耦**。
也就是说页面里只引用"某个条目 id 对应的图片"，不写死具体文件名，
后续把 AI 兜底图换成真实高清图时，不需要改任何页面代码。

## 体积红线

单个文件建议 ≤ 500KB（长边 1600px 以内）；不提交超过几十 MB 的大文件，
超大素材先问组长（见《GitHub 协作指南》第七章红线）。
